# REST API Documentation and Reference

The NEXORA Robotics backend provides a versioned REST API. Interactive OpenAPI/Swagger documentation is available at `/api-docs`.

---

## Base URLs
- **Local Development:** `http://localhost:5000/api`
- **Interactive Swagger UI:** `http://localhost:5000/api-docs`
- **Production Hosted (e.g. Render):** `https://nexora-backend.onrender.com/api`

---

## Authentication Header
Protected endpoints require an `Authorization` header containing the Supabase JWT access token:
```http
Authorization: Bearer <SUPABASE_JWT_ACCESS_TOKEN>
```

---

## 1. System Health Check

### `GET /api/health`
Verifies backend operational status, uptime, and database configuration.

#### Response `200 OK`
```json
{
  "status": "ok",
  "timestamp": "2026-10-20T04:30:15.123Z",
  "service": "nexora-backend",
  "environment": "development",
  "uptimeSeconds": 1420,
  "databaseConfigured": true
}
```

## 2. Profile Management

### `GET /api/v1/profile/me`
Retrieves the profile of the currently authenticated pilot.

#### Headers
```http
Authorization: Bearer <JWT>
```

#### Response `200 OK`
```json
{
  "success": true,
  "data": {
    "id": "e4b2d184-78fa-4a25-9c88-123456789abc",
    "display_name": "Commander Sarah",
    "avatar_url": "https://images.unsplash.com/photo-1534528741775-53994a69daeb?w=200",
    "bio": "Lead test pilot for NXR humanoid units.",
    "gender": "female",
    "hobbies": ["Robotics", "Drones", "AI"],
    "strengths": ["Rapid Prototyping", "Kinematics"],
    "created_at": "2026-10-20T03:15:00.000Z",
    "updated_at": "2026-10-20T04:22:10.500Z"
  }
}
```

#### Error Response `401 Unauthorized`
```json
{
  "success": false,
  "error": "Unauthorized: Missing or malformed Authorization header with Bearer token"
}
```

### `PATCH /api/v1/profile/me`
Updates profile fields. Input is strictly sanitized and validated using Zod.

#### Headers
```http
Authorization: Bearer <JWT>
Content-Type: application/json
```

#### Request Body
```json
{
  "display_name": "Commander Sarah Vance",
  "bio": "Senior robotics research lead and pilot.",
  "gender": "female",
  "hobbies": ["Autonomous Systems", "Quantum Logic"],
  "strengths": ["Leadership", "Telemetry Analysis"]
}
```

#### Response `200 OK`
```json
{
  "success": true,
  "message": "Profile updated successfully",
  "data": {
    "id": "e4b2d184-78fa-4a25-9c88-123456789abc",
    "display_name": "Commander Sarah Vance",
    "avatar_url": "https://images.unsplash.com/photo-1534528741775-53994a69daeb?w=200",
    "bio": "Senior robotics research lead and pilot.",
    "gender": "female",
    "hobbies": ["Autonomous Systems", "Quantum Logic"],
    "strengths": ["Leadership", "Telemetry Analysis"],
    "created_at": "2026-10-20T03:15:00.000Z",
    "updated_at": "2026-10-20T04:45:12.789Z"
  }
}
```

#### Error Response `400 Bad Request` (Validation Failure)
```json
{
  "success": false,
  "error": "Validation failed",
  "details": {
    "gender": ["Invalid enum value. Expected 'male' | 'female' | 'non-binary' | 'other' | 'unspecified'"]
  }
}
```

### `GET /api/v1/profile/me/audit-logs`
Retrieves historical modifications generated by the PostgreSQL database trigger.

#### Response `200 OK`
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "user_id": "e4b2d184-78fa-4a25-9c88-123456789abc",
      "action": "UPDATE",
      "old_data": { "bio": "Initial bio" },
      "new_data": { "bio": "Senior robotics research lead and pilot." },
      "performed_at": "2026-10-20T04:45:12.789Z"
    }
  ]
}
```
