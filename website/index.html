DECOUPLED ARCHITECTURE

How Any Frontend Connects to This System

Because this backend and database layer is completely independent, any client application (React Native, React, Vue, Flutter, iOS, Android) connects using standard REST or the Supabase SDK:

REST API (TypeScript / Express) Endpoints 
// 1. Health check
GET /api/health

// 2. Fetch authenticated record
GET /api/v1/profile/me
Headers: { "Authorization": "Bearer <JWT>" }

// 3. Update record & fire trigger
PATCH /api/v1/profile/me
Headers: { "Authorization": "Bearer <JWT>" }
Body: { "display_name": "...", "bio": "..." }
Supabase Client SDK Direct Client Integration 
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

// Google OAuth
await supabase.auth.signInWithOAuth({ provider: 'google' });

// Query database
const { data } = await supabase
  .from('profiles')
  .select('*')
  .eq('id', user.id);
