#NEXORA Robotics — Product Catalogue Plan

#Objective

Create an interactive product catalogue for the fictional NEXORA Robotics company.

#Product concepts

#1. NEXORA Home
A conceptual domestic humanoid designed for home assistance and smart-environment interaction.

#2. NEXORA Industrial
A conceptual industrial humanoid designed for logistics support and repetitive tasks.

#3. NEXORA Care
A conceptual companion humanoid designed for hospitality and guided assistance.

#Planned website features

- Responsive product cards
- Distinct visual identity for each product
- Interactive product-detail panels
- Concept specifications and feature lists
- Keyboard-accessible interactions
- Mobile-friendly layout

#Implementation approach

The catalogue will use HTML for structure, CSS for styling, and JavaScript for interactive behavior.

All robot capabilities and specifications will be labelled as fictional concepts.

#Status

Planning complete. Implementation pending.
